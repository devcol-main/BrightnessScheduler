# Brightness Scheduler — 처음 기획

> 이 문서는 프로젝트를 시작할 때의 기획을 기록합니다. 이후 버전별 변경은 [CHANGELOG.md](../CHANGELOG.md)에 남깁니다.
> 기획이 바뀌면 이 문서를 고치지 말고 아래 **기획 변경 기록**에 추가합니다.

## 1. 왜 만들었나

- 낮과 밤에 같은 밝기로 화면을 보면 밤에 눈이 피로하고, 매번 노트북 밝기와 모니터 OSD 버튼을 따로 조절하기 번거롭다.
- Windows 야간 모드는 색온도만 바꾸고, **외부 모니터의 밝기·대비**는 건드리지 못한다.
- 기존 도구는 기능이 많고 무겁거나, 노트북 화면과 외부 모니터를 한 번에 스케줄로 다루지 못한다.
- 목표: **설치 없이 exe 하나로, 시간표에 맞춰 모든 화면의 밝기·대비를 자동으로 맞추는 가벼운 트레이 앱.**

## 2. 대상 사용자

- 노트북 + 외부 모니터를 함께 쓰는 Windows 10/11 사용자
- 낮/저녁/밤에 다른 밝기를 원하지만 매번 손으로 바꾸기 싫은 사람
- 다른 프로그램(별도 런타임, 드라이버)을 설치하고 싶지 않은 사람

## 3. 핵심 기능 (MVP)

| 우선순위 | 기능 | 비고 |
|---|---|---|
| 필수 | 시간 기반 일정 (예: 07:00 주간, 22:00 야간) | 다음 일정까지 유지, 자정 넘김 처리 |
| 필수 | 노트북 내장 화면 밝기 | WMI (`WmiMonitorBrightnessMethods`) |
| 필수 | 외부 모니터 밝기·대비 | DDC/CI, VCP `0x10` / `0x12` |
| 필수 | 트레이 상주 + Windows 시작 시 자동 실행 | |
| 높음 | 디스플레이별·항목별 값 (체크 안 한 값은 그대로) | |
| 높음 | 절전·잠금 해제·모니터 연결 시 재적용 | 모니터가 값을 잊는 문제 대응 |
| 중간 | 요일 반복, 일시정지, 부드러운 전환 | |
| 중간 | 한국어/영어 UI, 라이트/다크 테마 | |
| 낮음 | 포터블 모드, 오늘의 타임라인 | |

## 4. 기술 선택

- **C# / WPF / .NET 10** — Windows 전용 데스크톱 앱, Win32 API(`dxva2.dll`) 호출이 쉬움.
- **MVVM 구조** — `Services`(스케줄·모니터·설정), `ViewModels`, `Views`로 분리.
- 설정은 `%APPDATA%\BrightnessScheduler\settings.json` (exe 옆에 있으면 포터블 모드).
- 배포: self-contained 단일 파일 exe(설치 불필요) + 런타임 필요한 소형 exe.
- 릴리스: 태그 push → GitHub Actions 빌드 → SignPath Foundation 무료 코드 서명 → GitHub Release.

## 5. 범위 밖 (하지 않는 것)

- 색온도/블루라이트 조절 (Windows 야간 모드에 맡김)
- 일출·일몰 위치 기반 자동 일정
- macOS / Linux 지원
